# py-rock-paper-scissors

A simple interactive Rock Paper Scissors game built in Python.

## Usage

```bash
python rpc.py
```

1. Choose your option: `Rock`, `Paper`, or `Scissors`
2. The computer makes its choice
3. The winner is determined
4. Choose to play again or quit

## Features

- Play against the computer
- Colorful terminal output
- Input validation for choices
- Play multiple rounds in a row
